# 🎯 屏幕自动点击助手 (macOS Python 版)

基于 Python 独立虚拟环境构建的现代化屏幕自动点击工具，支持屏幕取点、原子性 ABB 完整周期保障、B-B 独立随机落点与可调间隔、目标进程绑定防误触、锁屏安全自动暂停/恢复、Caffeinate 防锁屏常亮保持、带半径与漂移时间的随机偏移防检测、无限循环、配置自动记忆以及全局快捷键。

## ✨ 核心特性

- **🔁 原子性完整 ABB 周期（优雅停止）**：
  - 严格按照 `A 点 1 次` ➜ `A-B 间隔` ➜ `B 点第 1 次` ➜ `B-B 间隔` ➜ `B 点第 2 次` 完整周期执行。
  - 按下 `Esc` 或点击【⏹ 停止】时，**不会在中途掐断，而是确保完成当前这一整轮完整的 ABB 点击后再停止**，保证退出前必定完整执行过 B 点。
- **🎲 B1 / B2 独立随机落点**：
  - 两次 B 点的点击位置各自**独立在设定半径内重新进行均匀随机采样**，确保两次 B 点的落点各不相同，杜绝死板固定坐标。
- **⏱️ A-B 与 B-B 双重独立间隔与 ± 漂移**：
  - `A-B 间隔`：默认 `300ms ± 50ms`（可调）
  - `B-B 间隔`：默认 `100ms ± 20ms`（可调）
- **🛡️ 智能锁屏保护**：实时监测系统锁屏状态，锁屏时**自动挂起暂停点击**，解锁后**自动无缝恢复**。
- **☕ 防休眠/防锁屏保持 (Caffeinate)**：勾选后在自动化运行期间自动激活 macOS 电源防休眠机制，保持屏幕常亮不进入闲置锁屏。
- **🎯 目标进程绑定与防误触**：取点时自动识别鼠标落点所在的应用程序（App Name 与 PID），点击前自动唤醒/置顶目标窗口。
- **♾️ 无限循环点击**：支持设定指定执行轮数或一键勾选 **无限循环点击**。
- **🎨 现代 macOS 风格 GUI**：深浅色自适应、置顶悬浮窗、权限状态灯、等宽控制台日志、配置持久化。
